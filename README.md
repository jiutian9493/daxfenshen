# 大X分身 / DaX Clone

大X分身是一款面向 Android 的多空间应用分身工具，帮助你在一台设备上获得更独立、更清爽的应用使用体验。

## 功能特色

- 应用分身：为三方应用创建独立空间分身
- 独立数据：分身与原应用数据相互隔离
- 冻结管理：需要时冻结不常用的分身，减少后台占用
- 快速启动：从大X分身首页直接启动和管理
- 单应用单实例：每个应用在独立空间中最多创建一个分身
