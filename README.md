# 大X分身 / DaX Clone

大X分身是一款面向 Android 的独立空间应用分身工具，帮助你在同一台设备上为三方应用创建独立分身，减少账号和数据之间的相互干扰。

## 功能

- 为三方应用创建独立分身
- 分身与原应用数据隔离
- 支持冻结与解冻
- 从大X分身直接启动和管理
- 单个应用在独立空间中只创建一个分身

## 安装

1. 从 Releases 下载最新版 APK。
2. 按系统提示允许安装来源。
3. 打开大X分身并创建独立空间。
4. 选择三方应用创建分身。

安装或覆盖升级需要使用相同签名。卸载大X分身或移除独立空间会影响其中的分身数据，操作前请先备份重要数据。

## 常见问题

### 为什么需要独立空间？

独立空间用于隔离分身与原应用的数据，避免两者相互影响。

### 卸载后会删除分身吗？

卸载大X分身或移除受管资料会影响独立空间及其中的分身数据。

### 支持哪些 Android 版本？

建议使用 Android 10 及以上系统。不同厂商和系统版本对独立空间的支持可能存在差异，实际表现以设备为准。
