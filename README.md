# 大X分身 / DaX Clone

**为 Android 三方应用提供独立空间分身。**

大X分身是一款轻量的 Android 应用分身工具。它通过独立空间为三方应用创建分身，让分身与原应用的数据彼此隔离；安装后按引导即可开始使用，无需复杂设置。

## 主要特性

- **应用分身**：为三方应用创建独立分身。
- **数据隔离**：分身与原应用各自保存数据，互不干扰。
- **单分身设计**：同一应用在独立空间中只创建一个分身，管理更简单。
- **冻结与解冻**：暂时不用时可以冻结分身，需要时再恢复。
- **集中管理**：从大X分身直接启动和管理已有分身。
- **更新提示**：发现官方新版本时，应用内及时提醒。

## 常见问题

### 为什么需要独立空间？

独立空间用于隔离分身与原应用的数据，避免双方数据相互影响。

### 为什么同一个应用只创建一个分身？

当前版本采用单分身设计，减少重复配置并让管理更简单。

### 卸载后会删除分身吗？

会。卸载大X分身或移除独立空间会影响其中的分身数据，请提前备份。

### 如何获取新版本？

应用会在发现可用更新时提示；也可以从上方 Releases 页面下载新版 APK 覆盖安装。
